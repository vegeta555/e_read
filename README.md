# E Read Tool：安卓本地小说阅读器

这是一个从零开始练习安卓开发和 GitHub 协作流程的项目。已确认使用 Python + Kivy 开发安卓应用；第一版支持本地 TXT，书籍和进度只保存在手机上。

当前阶段完成了第一版需求规划和依赖清单，还没有创建应用或 Git 仓库。具体实现选型会在对应开发阶段与你确认。

## 从这里开始

1. 阅读[产品需求文档](docs/product-requirements.md)，了解已确认的首版范围和验收条件。
2. 按[初学者项目实操指南](docs/project-guide.md)准备 Python 虚拟环境、创建应用、分阶段开发和验证。
3. 指南中的 `git pull`、`git push`、创建及合并 Pull Request 都由你自己操作。每完成一个阶段，都能在 GitHub 上看到自己的提交记录。

计划把应用入口 `main.py` 放在仓库根目录，Windows 虚拟环境放在 `.venv/`。安卓 APK 的打包环境与 Windows 虚拟环境分开，详见实操指南。
