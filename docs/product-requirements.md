## 1. 产品目标

面向想在安卓手机上阅读自己拥有的 TXT 小说的用户，做一个操作简单、无需账号、无需联网的阅读器。用户能从手机选择文件、在书架找到它、阅读并接续上次的位置。

本项目同时用于学习完整开发流程：定义需求、拆分任务、编码、在模拟器或真机验证、提交代码、推送分支、创建和合并 Pull Request（PR）。

### 首版完成标准

在一台安卓设备或模拟器上，用户能独立完成以下连续操作：导入一个 UTF-8 TXT 文件 → 在书架打开 → 阅读并滚动 → 退出应用 → 重新打开同一本书，回到上次阅读的段落附近 → 调整字号和主题 → 删除书籍，并确认原始文件仍在。

## 2. 用户与使用场景

- **目标用户**：已经有本地 TXT 小说，希望专注、离线阅读的安卓手机用户。
- **场景 A**：用户从系统文件选择器选择下载目录中的 TXT，导入后立即阅读。
- **场景 B**：用户在通勤时离线打开书架，继续上次读到的位置。
- **场景 C**：用户觉得字太小，调大字号；下次打开仍保留这一设置。

## 4. 关键交互流程

### 导入

书架点击“导入 TXT” → 选择文件 → 选择编码（默认 UTF-8；乱码时可改用 GB18030） → 校验大小与内容 → 按 M2 确认的方案保存访问能力或应用内副本 → 解析段落 → 加入书架 → 打开阅读页。

如果导入失败，保持书架原状并展示明确原因。再次导入同一文件时，首版允许出现两条独立书籍，书架通过文件名和导入时间区分；后续可加入去重。

### 阅读与接续

书架选书 → 阅读页恢复保存的位置 → 滚动阅读 → 保存段落索引和该段落内偏移/滚动偏移 → 返回书架或退出 → 再次进入时恢复。字号改变后允许位置有小幅偏差，但应保持在同一段落附近。

### 删除

书架长按或点击书籍菜单 → “删除” → 弹窗说明不会删除手机原始文件 → 确认 → 移除应用中的书籍与进度。取消时不改变任何数据。

## 5. 页面与文案

| 页面 | 核心元素 | 空状态或错误提示 |
| --- | --- | --- |
| 书架 | 标题、导入按钮、书籍列表、书籍菜单 | “书架还是空的，导入一本 TXT 开始阅读” |
| 导入 | 手机文件选择入口、编码选择（必要时） | “文件为空”“文件超过 20 MB”“无法读取这个 TXT 文件” |

第一版以中文界面、手机竖屏为主；系统返回键应能回到书架。正文留出安全边距，避免紧贴屏幕边缘。

## 6. 数据与技术方案

- **客户端（已确认）**：Python + Kivy。先在 Windows 虚拟环境运行界面；安卓 APK 可用 Kivy 官方推荐的 Buildozer 流程打包，也可直接使用 python-for-android，M2 前由你确认。
- **Python 版本**：当前电脑的 Python 为 3.12.7；Kivy 2.3.1 官方支持 Python 3.8–3.13。本地开发先使用项目根目录的 `.venv/`，它不提交到 Git。
- **安卓版本（待确认）**：在首次 APK 打包前，结合目标手机与 Buildozer 配置决定最低安卓版本和目标 API。
- **文件导入候选**：手机文件选择与访问可通过 Kivy 提供的组件或安卓平台接口实现；读取后保存应用内副本，或保留文件引用。M2 前确认具体方式，并以安卓真机/模拟器测试为准。
- **本地数据候选**：书籍记录与进度可用 Python 标准库 `sqlite3`；少量全局设置可用 `json` 或 Kivy 的 JsonStore。M2/M4 开始前由你确认。首版无需为这些能力预装额外第三方库。
- **正文处理**：导入时解析 TXT 为段落；阅读页分段或分块呈现，避免把整本书放进单个超长控件。首版目标文件上限 20 MB，需要在真实设备上验证内存与滚动体验。
- **建议数据字段**：`Book(id, title, internalPath, encoding, importedAt, lastReadAt, totalParagraphs)`；`ReadingProgress(bookId, paragraphIndex, offset, updatedAt)`；`ReaderSettings(fontSize, theme)`。具体字段可以在实现时小幅调整，前提是满足验收要求。
- **隐私**：书籍和进度仅保存在设备本地；首版不接入账号、统计或网络接口。

## 7. 非功能要求

- **可用性**：导入、保存、删除都给出可理解的结果；读取失败不应导致应用崩溃。
- **性能**：普通中文 TXT（例如 1–5 MB）打开后能正常滚动；20 MB 上限是待设备实测的初始约束，如性能不足，应降低上限并更新文档。
- **数据安全**：只有导入并校验成功才加入书架；删除前二次确认；书籍记录与应用保存的文件或引用保持一致。
- **可访问性**：按钮有可读标签，字号有明显可见的调整效果，正文与背景保持足够对比。
- **测试**：至少用一台模拟器或真机完整走通“导入 → 阅读 → 退出 → 恢复 → 删除”，并覆盖空文件、超限文件、乱码选择与读取失败。
